# Cookify — React frontend

See the top-level `../README.md` for full project context, setup, and design notes.

```bash
npm install
npm run dev           # local dev server with HMR — proxies /api to the backend on :8000
npm run build         # outputs to dist/, served by the backend in single-process mode
npm run lint          # oxlint
npm run format        # prettier --write
npm run format:check  # prettier --check, no changes written
```
